# CourseHub — платформа IT-курсів

Навчальний проєкт: односторінковий сайт-лендінг платформи IT-курсів.

**Демо:** https://ТВІЙ_USERNAME.github.io/coursehub/

## Що всередині
- Адаптивна верстка (media queries 1200px / 900px / 600px)
- Бургер-меню на чистому CSS
- Секції з фоновим зображенням і фоновим відео
- Форми входу й реєстрації, таблиця тарифів
- UI-компоненти: кнопки з модифікаторами, блок з тарифними пакетами
- CSS-анімації: transition, transform, @keyframes, підтримка prefers-reduced-motion

## Технології
HTML5, CSS3, Flexbox, Grid, медіа-запити. Без фреймворків і бібліотек.
